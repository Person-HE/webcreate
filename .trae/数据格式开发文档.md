# 逐帧动画数据格式开发文档

## 1. 概述

本文档详细说明了如何通过JSON数据创建逐帧动画。每个JSON中的`layer`对应画布上的一个独立图层/帧，通过多个帧的连续播放实现丝滑的动画效果。

## 2. 核心概念

### 2.1 图层即帧

- **每个layer = 一个独立的帧**
- JSON中的`layers`数组包含多个帧
- 导入时，系统会为每个layer创建独立的图层
- 播放动画时，按图层顺序依次显示每一帧

### 2.2 动画丝滑的关键

要实现丝滑的逐帧动画，需要：

1. **足够的帧数**：动画越复杂，需要的帧数越多
2. **帧间变化小**：相邻帧之间的变化越小，动画越丝滑
3. **一致的元素ID**：同一元素在不同帧中保持相同的`id`，便于补间动画
4. **合理的帧率**：一般12-24帧/秒

## 3. 数据结构详解

### 3.1 顶层结构

```json
{
  "canvasWidth": 1920,       // 画布宽度（像素）
  "canvasHeight": 1080,      // 画布高度（像素）
  "backgroundColor": "#ffffff", // 画布背景颜色（十六进制）
  "layers": []               // 图层/帧数组
}
```

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| canvasWidth | number | 否 | 画布宽度，默认1920像素 |
| canvasHeight | number | 否 | 画布高度，默认1080像素 |
| backgroundColor | string | 否 | 画布背景颜色，十六进制格式，如"#ffffff" |
| layers | array | 是 | 图层/帧数组，每个元素代表一帧 |

### 3.2 图层（帧）结构

```json
{
  "id": "frame-1",           // 图层唯一标识
  "name": "第一帧",          // 图层名称
  "visible": true,           // 是否可见
  "locked": false,           // 是否锁定
  "opacity": 100,            // 不透明度（0-100）
  "elements": []             // 该帧包含的元素数组
}
```

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | string | 否 | 自动生成 | 图层唯一标识符 |
| name | string | 否 | "帧 N" | 图层名称，建议使用有意义的名称如"眨眼1"、"眨眼2" |
| visible | boolean | 否 | true | 图层是否可见，false则该帧不参与动画播放 |
| locked | boolean | 否 | false | 图层是否锁定，锁定后无法编辑 |
| opacity | number | 否 | 100 | 图层不透明度，0为完全透明，100为完全不透明 |
| elements | array | 是 | [] | 该帧包含的元素数组，详见下文 |

### 3.3 元素通用属性

每个元素都必须包含以下基础属性：

```json
{
  "id": "element-1",         // 元素唯一标识
  "type": "rectangle",       // 元素类型
  "x": 100,                  // 左上角x坐标
  "y": 100,                  // 左上角y坐标
  "width": 200,              // 宽度
  "height": 150,             // 高度
  "angle": 0,                // 旋转角度
  "strokeColor": "#000000",  // 笔触颜色
  "backgroundColor": "#ffffff", // 填充颜色
  "fillStyle": "solid",      // 填充样式
  "strokeWidth": 2,          // 笔触宽度
  "strokeStyle": "solid",    // 笔触样式
  "roughness": 0.5,          // 粗糙度
  "opacity": 100,            // 不透明度
  "visible": true,           // 是否可见
  "strokeSharpness": "round", // 笔触锐利度
  "cornerRadius": 0          // 圆角半径（仅矩形）
}
```

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | string | 是 | - | **元素唯一标识符，同一元素在不同帧中应保持相同id** |
| type | string | 是 | - | 元素类型，见下表 |
| x | number | 是 | 0 | 元素边界框左上角的x坐标（像素） |
| y | number | 是 | 0 | 元素边界框左上角的y坐标（像素） |
| width | number | 是 | 0 | 元素宽度（像素） |
| height | number | 是 | 0 | 元素高度（像素） |
| angle | number | 否 | 0 | 旋转角度（度），正值为顺时针旋转 |
| strokeColor | string | 否 | "#000000" | 笔触/边框颜色，十六进制格式 |
| backgroundColor | string | 否 | "transparent" | 填充颜色，"transparent"表示透明 |
| fillStyle | string | 否 | "none" | 填充样式：none(无填充)、solid(纯色填充) |
| strokeWidth | number | 否 | 2 | 笔触/边框宽度（像素） |
| strokeStyle | string | 否 | "solid" | 笔触样式：solid(实线)、dashed(虚线)、dotted(点线) |
| roughness | number | 否 | 1 | 粗糙度(0-2)，值越大手绘感越强，0为平滑线条 |
| opacity | number | 否 | 100 | 不透明度(0-100)，0为完全透明 |
| visible | boolean | 否 | true | 元素是否可见 |
| strokeSharpness | string | 否 | "round" | 笔触锐利度：round(圆滑)、sharp(锐利) |
| cornerRadius | number | 否 | 0 | 圆角半径（仅矩形有效），0为直角 |

### 3.4 元素类型

| 类型 | 说明 | 特殊属性 |
|------|------|----------|
| free_draw | 画笔自由绘制 | points（必需） |
| rectangle | 矩形 | cornerRadius（可选） |
| ellipse | 椭圆/圆形 | - |
| diamond | 菱形 | - |
| line | 直线 | - |
| arrow | 箭头 | - |
| text | 文本 | text, fontSize, fontFamily, textAlign |
| image | 图片 | imageUrl |

### 3.5 画笔绘制元素（free_draw）

画笔绘制元素需要额外的`points`属性：

```json
{
  "id": "line-1",
  "type": "free_draw",
  "x": 100,
  "y": 100,
  "width": 200,
  "height": 100,
  "strokeColor": "#3b82f6",
  "strokeWidth": 3,
  "roughness": 0.5,
  "points": [
    [100, 100, 1],   // [x, y, pressure]
    [150, 120, 0.8],
    [200, 150, 1],
    [250, 180, 0.9],
    [300, 200, 1]
  ]
}
```

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| points | array | 是 | 画笔路径点数组，每个点格式为[x, y, pressure] |

**点格式详解**：
- `x`：点的x坐标（像素，绝对坐标）
- `y`：点的y坐标（像素，绝对坐标）
- `pressure`：压力值（0-1），影响线条粗细，1为最粗

**点密度建议**：
| 线条类型 | 建议点间距 | 说明 |
|----------|------------|------|
| 直线 | 10-15像素 | 较稀疏即可 |
| 平滑曲线 | 5-8像素 | 中等密度 |
| 急转弯曲线 | 2-4像素 | 高密度捕捉细节 |

### 3.6 文本元素（text）

```json
{
  "id": "text-1",
  "type": "text",
  "x": 100,
  "y": 100,
  "width": 200,
  "height": 30,
  "strokeColor": "#000000",
  "text": "Hello World",
  "fontSize": 24,
  "fontFamily": "Virgil",
  "textAlign": "left"
}
```

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| text | string | 是 | - | 文本内容 |
| fontSize | number | 否 | 24 | 字体大小（像素） |
| fontFamily | string | 否 | "Virgil" | 字体名称 |
| textAlign | string | 否 | "left" | 对齐方式：left、center、right |

### 3.7 图片元素（image）

```json
{
  "id": "image-1",
  "type": "image",
  "x": 100,
  "y": 100,
  "width": 200,
  "height": 150,
  "imageUrl": "data:image/png;base64,..."
}
```

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| imageUrl | string | 是 | 图片URL或Base64编码数据 |

## 4. 创建丝滑动画的指南

### 4.1 帧数规划

| 动画类型 | 建议帧数 | 帧率 | 说明 |
|----------|----------|------|------|
| 简单眨眼 | 3-5帧 | 12 FPS | 闭眼-睁开-恢复 |
| 行走循环 | 8-12帧 | 12 FPS | 一个完整的步态周期 |
| 跑步循环 | 6-8帧 | 24 FPS | 更快的动作需要更高帧率 |
| 表情变化 | 5-8帧 | 12 FPS | 渐变表情 |
| 物体变形 | 10-20帧 | 24 FPS | 形状变化需要更多帧 |

### 4.2 元素ID一致性

**重要**：同一元素在不同帧中必须保持相同的`id`，这样系统才能进行补间动画。

```json
// 帧1
{
  "id": "eye-left",  // 眼睛ID
  "type": "ellipse",
  "height": 40      // 睁眼状态
}

// 帧2
{
  "id": "eye-left",  // 相同ID
  "type": "ellipse", 
  "height": 10       // 闭眼状态
}

// 帧3
{
  "id": "eye-left",  // 相同ID
  "type": "ellipse",
  "height": 40       // 恢复睁眼
}
```

### 4.4 动画丝滑的关键点

1. **帧间变化小**：相邻帧之间，元素属性变化越小越好
   - 眨眼动画中，眼睛高度从40→20→4→20→40，每次变化约20像素

2. **保持元素ID一致**：同一元素在各帧中使用相同的`id`
   - "eye-left"在所有帧中保持相同ID

3. **不变的元素完全复制**：不变化的元素（如face、mouth）在各帧中保持完全相同

4. **适当的帧数**：
   - 简单动画：3-5帧
   - 中等复杂：5-10帧
   - 复杂动画：10-20帧

## 5. 高质量线条生成

### 5.1 路径平滑

系统在导入时会自动应用平滑算法，消除AI生成坐标的抖动。

### 5.2 点数重采样

对于画笔绘制元素，系统会对路径点进行重采样，确保前后帧点数一致，实现丝滑的路径变形动画。

### 5.3 全局包围盒计算

导入时系统会计算所有元素的全局包围盒，应用统一偏移，确保元素相对位置正确。

## 7. 故障排除

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 所有内容显示在一个图层 | JSON格式错误或导入逻辑问题 | 确保每个layer有独立的elements数组 |
| 动画不丝滑 | 帧数不足或帧间变化太大 | 增加帧数，减小相邻帧的变化 |
| 元素位置错乱 | 坐标计算错误 | 使用统一的全局包围盒计算 |
| 线条僵硬 | AI生成的点抖动大 | 系统会自动平滑，或手动增加点密度 |
| 元素消失 | 元素ID不一致 | 确保同一元素在各帧中保持相同ID |

## 8. 总结

创建丝滑逐帧动画的关键：

1. **每个layer对应一个独立的帧**
2. **同一元素在各帧中保持相同的ID**
3. **相邻帧之间的变化要小**
4. **使用足够的帧数**
5. **保持不变的元素在各帧中完全复制**

按照本文档规范构建JSON数据，系统会自动处理平滑、重采样和定位，渲染出高质量的逐帧动画。
