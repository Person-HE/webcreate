# WebCreate 动画系统完整规范

> 本文档定义了 WebCreate 动画系统的完整规范，包括动画灵魂四大原则、缓动系统、拖影系统、JSON 数据格式，以及 AI 生成动画 JSON 的完整指南。
> AI 应根据此文档生成符合格式的 JSON 代码，以在 WebCreate 画布上渲染出丝滑、有灵魂的动画效果。

---

## 一、动画灵魂四大原则

### 原则1：遵循慢进慢出运动规律

**核心理念**：摒弃生硬匀速运动，按照现实惯性做「慢→快→慢」变速运动。

**技术实现**：
- 首尾帧间距密集（速度慢），运动中段帧间距松散（速度快）
- 通过缓动函数（Easing Function）控制时间-位移映射
- **绝对禁止使用 `linear`（匀速）作为默认运动方式**，除非是旋转或匀速平移等特殊场景

**AI 生成规则**：
- 位移动画默认使用 `easeInOutCubic`（平滑慢-快-慢）
- 淡入淡出默认使用 `easeInOutSine`（最柔和的慢-快-慢）
- 缩放弹入使用 `easeOutBack`（超过目标后回弹）
- 重物下落使用 `easeInExpo`（几乎不动然后突然加速）

### 原则2：依托运动曲线塑造质感

**核心理念**：借助变速曲线区分物体重量和材质。

**技术实现**：
- 轻物体（羽毛、气泡）：使用弹性缓动 `easeOutElastic`，有回弹振荡
- 重物体（铁球、石块）：使用指数缓动 `easeOutExpo`，沉稳无反弹
- 弹性物体（弹簧、橡皮球）：使用弹簧物理 `spring`，真实振荡衰减
- 落地物体（球、箱子）：使用重力物理 `gravity`，真实弹跳衰减
- 搭配镜头震动（Camera Shake）辅助强化受力效果

**AI 生成规则**：
- 每个动画模板必须指定 `easingConfig`，按属性分别设置缓动
- 位移（position）和缩放（scale）应使用不同的缓动曲线
- 重物落地场景：position 用 `easeInExpo`，scale 用 `easeOutBounce`
- 轻物飘浮场景：position 用 `easeOutElastic`，scale 用 `easeOutElastic`

### 原则3：巧用慢进慢出做顺滑转场

**核心理念**：依靠变速运动衔接画面元素，实现物体形态、画面场景的平稳过渡。

**技术实现**：
- 转场使用 `easeInOutCubic` 或 `easeInOutSine` 作为主缓动
- 元素交错出场（Stagger）：不同元素按序延迟出现，避免所有元素同时运动
- 形态变形（Morphing）：前后帧的 `free_draw` 元素通过点重采样实现平滑变形
- 淡入淡出配合位移：元素在移动中淡入，移动中淡出，而非原地闪现

**AI 生成规则**：
- 多元素动画必须设置 `stagger`（交错出场）
- 场景切换动画：前帧元素 `easeOutCubic` 淡出，后帧元素 `easeInCubic` 淡入
- 形状变形动画：前后帧使用相同 `id` 的 `free_draw` 元素，系统自动做路径插值

### 原则4：合理运用拖影补充运动轨迹

**核心理念**：高速动作帧跨度大时，叠加连续画面形成拖影，补足视觉连贯感。

**技术实现**：
- 系统自动检测元素位移速度，超过阈值时自动渲染拖影
- 拖影是运动轨迹上的半透明残影，透明度按指数衰减
- 仅在高速运动场景使用，低速运动不显示拖影
- 拖影长度与运动速度成正比

**AI 生成规则**：
- 高速运动动画（弹跳、飞入、快速滑动）必须设置 `trail.enabled: true`
- 缓慢动画（淡入、缓慢缩放）设置 `trail.enabled: false`
- 拖影参数根据运动速度调整：
  - 极速运动（>100px/帧）：`trailCount: 5, trailDecay: 0.4`
  - 快速运动（50-100px/帧）：`trailCount: 3, trailDecay: 0.5`
  - 中速运动（30-50px/帧）：`trailCount: 2, trailDecay: 0.6`

## 二、缓动函数完整参考

### 2.1 缓动类型一览

| 缓动名称 | 中文名 | 运动特征 | 适用场景 |
|----------|--------|----------|----------|
| `linear` | 匀速 | 无加减速，匀速运动 | 旋转、匀速平移 |
| `easeInQuad` | 慢进(二次) | 缓慢启动，逐渐加速 | 物体开始移动 |
| `easeOutQuad` | 慢出(二次) | 快速启动，缓慢停止 | 轻物体减速 |
| `easeInOutQuad` | 慢进慢出(二次) | 慢启动→加速→慢停止 | UI元素移动 |
| `easeInCubic` | 慢进(三次) | 更缓慢启动，加速更明显 | 重物启动 |
| `easeOutCubic` | 慢出(三次) | 快启动，柔和减速停止 | **通用减速，默认推荐** |
| `easeInOutCubic` | 慢进慢出(三次) | 平滑的慢-快-慢 | **通用位移，最常用** |
| `easeOutQuart` | 慢出(四次) | 快速启动，非常柔和停止 | 弹窗出现 |
| `easeInOutQuart` | 慢进慢出(四次) | 更明显的慢-快-慢 | 页面切换 |
| `easeInQuint` | 慢进(五次) | 极度缓慢启动 | 蓄力动作 |
| `easeOutQuint` | 慢出(五次) | 极度柔和停止 | 精致减速 |
| `easeInOutQuint` | 慢进慢出(五次) | 最明显的慢-快-慢 | 重要元素移动 |
| `easeInSine` | 慢进(正弦) | 最柔和的缓慢启动 | 淡入效果 |
| `easeOutSine` | 慢出(正弦) | 最柔和的缓慢停止 | 淡出效果 |
| `easeInOutSine` | 慢进慢出(正弦) | **最平滑的慢-快-慢** | **丝滑转场首选** |
| `easeInExpo` | 慢进(指数) | 几乎不动然后突然加速 | 爆炸前蓄力 |
| `easeOutExpo` | 慢出(指数) | 急速后突然减速停止 | 重物落地 |
| `easeInOutExpo` | 慢进慢出(指数) | 极慢→极快→极慢 | 戏剧性运动 |
| `easeInCirc` | 慢进(圆弧) | 圆弧形缓慢启动 | 有机运动启动 |
| `easeOutCirc` | 慢出(圆弧) | 圆弧形柔和停止 | 有机运动停止 |
| `easeInOutCirc` | 慢进慢出(圆弧) | 圆弧形慢-快-慢 | 自然运动 |
| `easeInBack` | 回弹进 | 先回退再前进 | 弹性出现 |
| `easeOutBack` | 回弹出 | 超过目标后回弹 | **弹性缩放、弹入** |
| `easeInOutBack` | 回弹进回弹出 | 回退→前进→超过→回弹 | 弹性移动 |
| `easeOutElastic` | 橡皮筋出 | 像橡皮筋一样振荡停止 | **弹簧效果、轻物回弹** |
| `easeInElastic` | 橡皮筋进 | 振荡式启动 | 特殊效果 |
| `easeInOutElastic` | 橡皮筋进出 | 振荡式启动和停止 | 趣味动画 |
| `easeOutBounce` | 弹跳出 | 像球落地一样弹跳 | **弹跳落地** |
| `easeInBounce` | 弹跳进 | 反向弹跳启动 | 特殊效果 |
| `easeInOutBounce` | 弹跳进出 | 弹跳式启动和停止 | 趣味弹跳 |
| `spring` | 弹簧物理 | 真实弹簧物理模拟 | 物理回弹、弹性交互 |
| `gravity` | 重力物理 | 真实重力弹跳模拟 | 掉落弹跳 |

### 2.2 缓动曲线选择决策树

```
需要动画效果？
├── 位移（位置变化）
│   ├── 通用移动 → easeInOutCubic
│   ├── 丝滑转场 → easeInOutSine
│   ├── 滑入 → easeOutCubic
│   ├── 滑出 → easeInCubic
│   ├── 重物下落 → easeInExpo
│   ├── 轻物飘浮 → easeOutElastic
│   ├── 弹性弹入 → easeOutBack
│   └── 物理掉落 → gravity
├── 缩放（大小变化）
│   ├── 通用缩放 → easeOutCubic
│   ├── 弹性弹入 → easeOutBack
│   ├── 橡皮筋效果 → easeOutElastic
│   ├── 重物落地 → easeOutBounce
│   └── 弹簧效果 → spring
├── 旋转（角度变化）
│   ├── 通用旋转 → easeInOutCubic
│   └── 惯性旋转 → easeOutCubic
├── 透明度（淡入淡出）
│   ├── 通用淡入淡出 → easeInOutSine
│   ├── 淡入 → easeOutSine
│   └── 淡出 → easeInSine
└── 路径变形（free_draw）
    └── 通用变形 → easeInOutCubic
```

### 2.3 弹簧物理参数

当使用 `spring` 缓动时，需要配置 `springConfig`：

```json
{
  "springConfig": {
    "mass": 1,
    "stiffness": 180,
    "damping": 12,
    "initialVelocity": 0
  }
}
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `mass` | number | 1 | 质量，越大振荡越慢 |
| `stiffness` | number | 170 | 刚度，越大回弹越快 |
| `damping` | number | 26 | 阻尼，越大振荡衰减越快 |
| `initialVelocity` | number | 0 | 初始速度 |

**预设配置**：

| 预设名 | mass | stiffness | damping | 效果 |
|--------|------|-----------|---------|------|
| gentle | 1 | 120 | 14 | 温和回弹 |
| bouncy | 1 | 180 | 10 | 活泼弹跳 |
| stiff | 1 | 300 | 30 | 刚性快速 |
| slow | 2 | 80 | 20 | 缓慢回弹 |
| elastic | 0.8 | 200 | 8 | 高弹性振荡 |
| heavy | 3 | 200 | 25 | 沉重缓慢 |

### 2.4 重力物理参数

当使用 `gravity` 缓动时，需要配置 `gravityConfig`：

```json
{
  "gravityConfig": {
    "gravity": 9.8,
    "bounceRestitution": 0.5,
    "initialHeight": 1,
    "groundLevel": 0
  }
}
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `gravity` | number | 9.8 | 重力加速度 |
| `bounceRestitution` | number | 0.6 | 弹跳恢复系数（0=不弹，1=完全弹性） |
| `initialHeight` | number | 1 | 初始高度（归一化） |
| `groundLevel` | number | 0 | 地面高度（归一化） |

## 三、动画 JSON 数据格式

### 3.1 顶层结构

```json
{
  "layers": [
    {
      "id": "layer-1",
      "name": "帧1",
      "visible": true,
      "elements": [ ... ]
    },
    {
      "id": "layer-2",
      "name": "帧2",
      "visible": true,
      "elements": [ ... ]
    }
  ],
  "animationConfig": {
    "fps": 24,
    "easingConfig": { ... },
    "trail": { ... },
    "stagger": { ... }
  },
  "description": "动画描述"
}
```

### 3.2 animationConfig 动画配置

```json
{
  "animationConfig": {
    "fps": 24,
    "easingConfig": {
      "position": "easeInOutCubic",
      "scale": "easeOutBack",
      "rotation": "easeInOutCubic",
      "opacity": "easeInOutSine",
      "path": "easeInOutCubic",
      "springConfig": { "mass": 1, "stiffness": 180, "damping": 12 },
      "gravityConfig": { "gravity": 9.8, "bounceRestitution": 0.5, "initialHeight": 1, "groundLevel": 0 }
    },
    "trail": {
      "enabled": true,
      "trailCount": 3,
      "trailDecay": 0.5,
      "speedThreshold": 30
    },
    "stagger": {
      "enabled": true,
      "delayPerElement": 0.05,
      "maxDelay": 0.3
    }
  }
}
```

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `fps` | number | ❌ | 12 | 帧率，建议 12-30 |
| `easingConfig` | object | ❌ | 见下方 | 缓动配置 |
| `trail` | object | ❌ | 见下方 | 拖影配置 |
| `stagger` | object | ❌ | 见下方 | 交错出场配置 |

### 3.3 easingConfig 缓动配置

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `position` | EasingType | `"easeInOutCubic"` | 位移缓动 |
| `scale` | EasingType | `"easeOutBack"` | 缩放缓动 |
| `rotation` | EasingType | `"easeInOutCubic"` | 旋转缓动 |
| `opacity` | EasingType | `"easeInOutSine"` | 透明度缓动 |
| `path` | EasingType | `"easeInOutCubic"` | 路径变形缓动 |
| `springConfig` | object | null | 弹簧物理参数（position/scale 为 spring 时使用） |
| `gravityConfig` | object | null | 重力物理参数（position 为 gravity 时使用） |

### 3.4 trail 拖影配置

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `enabled` | boolean | `true` | 是否启用拖影 |
| `trailCount` | number | 4 | 拖影层数（2-6） |
| `trailDecay` | number | 0.6 | 透明度衰减系数（0.3-0.8） |
| `speedThreshold` | number | 50 | 触发拖影的速度阈值（像素/帧） |

### 3.5 stagger 交错出场配置

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `enabled` | boolean | `false` | 是否启用交错出场 |
| `delayPerElement` | number | 0.05 | 每个元素的延迟时间（归一化 0-1） |
| `maxDelay` | number | 0.3 | 最大延迟时间（归一化 0-1） |

## 四、动画帧设计原则

### 4.1 帧与图层的关系

WebCreate 中**每个图层代表一帧**。动画播放时，系统按图层顺序依次播放，并在相邻帧之间进行插值过渡。

**关键规则**：
- 图层顺序 = 播放顺序（layer-1 → layer-2 → layer-3 → ... → 循环）
- 相邻帧中**相同 id 的元素**会被插值过渡（位移、缩放、旋转、透明度、路径变形）
- 相邻帧中**不同 id 的元素**会做淡入淡出过渡
- 每帧的 `elements` 数组中，元素渲染顺序为数组顺序（后面的覆盖前面的）

### 4.2 元素 ID 匹配规则

**核心原则**：如果两帧中某个元素的 `id` 相同且 `type` 相同，系统会自动做平滑插值过渡。

```
帧1: [{ id: "ball", x: 100, y: 100 }, { id: "bg", ... }]
帧2: [{ id: "ball", x: 500, y: 300 }, { id: "bg", ... }]
→ ball 从 (100,100) 平滑移动到 (500,300)，bg 保持不变
```

**AI 生成规则**：
- 需要做动画过渡的元素，**必须在不同帧中保持相同的 `id`**
- 不需要动画的静态元素（如背景），也保持相同 `id`，只是坐标不变
- 新出现的元素使用新 `id`，会自动淡入
- 消失的元素在后续帧中不出现，会自动淡出

### 4.3 帧数与动画时长

| 动画类型 | 建议帧数 | 建议FPS | 动画时长 |
|----------|----------|---------|----------|
| 简单位移 | 2 帧 | 12 | ~0.17s |
| 弹入效果 | 2 帧 | 24 | ~0.08s |
| 弹跳落地 | 2 帧 | 30 | ~0.07s |
| 逐帧动画 | 8-24 帧 | 12-24 | 0.5-2s |
| 场景动画 | 20-40 帧 | 24 | 1-2s |
| 复杂动画 | 30-60 帧 | 24-30 | 1-2.5s |

**注意**：帧数越多、FPS 越高，动画越流畅，但数据量也越大。对于简单过渡，2帧+高FPS+缓动即可实现丝滑效果。

## 五、动画类型与推荐配置

### 5.1 位移动画（Slide）

```json
{
  "animationConfig": {
    "fps": 24,
    "easingConfig": {
      "position": "easeInOutCubic",
      "opacity": "easeInOutSine"
    },
    "trail": { "enabled": false }
  }
}
```

**适用**：元素从A点移动到B点

### 5.2 弹入动画（Bounce In）

```json
{
  "animationConfig": {
    "fps": 30,
    "easingConfig": {
      "position": "easeOutBack",
      "scale": "easeOutBack",
      "opacity": "easeOutSine"
    },
    "trail": { "enabled": true, "trailCount": 3, "trailDecay": 0.5, "speedThreshold": 30 }
  }
}
```

**适用**：元素弹入画面，有回弹效果

### 5.3 重力掉落动画（Drop）

```json
{
  "animationConfig": {
    "fps": 30,
    "easingConfig": {
      "position": "gravity",
      "scale": "easeOutBounce",
      "gravityConfig": { "gravity": 9.8, "bounceRestitution": 0.5, "initialHeight": 1, "groundLevel": 0 }
    },
    "trail": { "enabled": true, "trailCount": 4, "trailDecay": 0.4, "speedThreshold": 50 }
  }
}
```

**适用**：物体从上方掉落并弹跳

### 5.4 弹簧动画（Spring）

```json
{
  "animationConfig": {
    "fps": 30,
    "easingConfig": {
      "position": "spring",
      "scale": "spring",
      "springConfig": { "mass": 1, "stiffness": 180, "damping": 12 }
    },
    "trail": { "enabled": false }
  }
}
```

**适用**：弹性交互、物理回弹

### 5.5 淡入淡出动画（Fade）

```json
{
  "animationConfig": {
    "fps": 24,
    "easingConfig": {
      "opacity": "easeInOutSine"
    },
    "trail": { "enabled": false }
  }
}
```

**适用**：元素渐显渐隐

### 5.6 丝滑转场动画（Smooth Transition）

```json
{
  "animationConfig": {
    "fps": 24,
    "easingConfig": {
      "position": "easeInOutCubic",
      "scale": "easeInOutSine",
      "rotation": "easeInOutCubic",
      "opacity": "easeInOutSine",
      "path": "easeInOutCubic"
    },
    "stagger": { "enabled": true, "delayPerElement": 0.05, "maxDelay": 0.3 },
    "trail": { "enabled": false }
  }
}
```

**适用**：场景切换、多元素协调运动

### 5.7 飘落动画（Float Down）

```json
{
  "animationConfig": {
    "fps": 24,
    "easingConfig": {
      "position": "easeInOutSine",
      "rotation": "easeInOutCubic",
      "opacity": "easeInOutSine"
    },
    "trail": { "enabled": true, "trailCount": 4, "trailDecay": 0.4, "speedThreshold": 20 }
  }
}
```

**适用**：树叶飘落、雪花飘落、气泡上升

### 5.8 心跳/脉冲动画（Pulse）

```json
{
  "animationConfig": {
    "fps": 24,
    "easingConfig": {
      "scale": "easeOutElastic",
      "opacity": "easeInOutSine"
    },
    "trail": { "enabled": false }
  }
}
```

**适用**：心跳、呼吸、脉冲效果

## 七、AI 生成动画 JSON 的完整流程

### 步骤1：确定动画类型

根据用户描述，选择合适的动画类型：

| 用户描述关键词 | 推荐动画类型 | 推荐缓动 |
|---------------|-------------|---------|
| 弹跳/掉落/落下 | 重力掉落 | gravity + easeOutBounce |
| 弹入/弹出/弹窗 | 弹簧弹入 | spring / easeOutBack |
| 飘落/飘浮/落下 | 飘落 | easeInOutSine |
| 淡入/渐显/出现 | 淡入 | easeInOutSine |
| 淡出/渐隐/消失 | 淡出 | easeInOutSine |
| 移动/滑动/飞入 | 位移 | easeInOutCubic |
| 缩放/放大/缩小 | 缩放 | easeOutBack / easeOutElastic |
| 旋转/转动 | 旋转 | easeInOutCubic |
| 变形/变形过渡 | 路径变形 | easeInOutCubic |
| 切换/转场/过渡 | 丝滑转场 | easeInOutCubic + stagger |
| 心跳/脉冲/呼吸 | 脉冲 | easeOutElastic |
| 弹性/弹簧/回弹 | 弹簧 | spring |

### 步骤2：设计关键帧

1. 确定需要几帧（最少2帧：起始帧 + 结束帧）
2. 每帧是一个图层，包含该帧的所有元素
3. 需要做动画的元素在所有帧中保持相同 `id`
4. 静态元素（背景等）在所有帧中保持相同 `id` 和相同坐标

### 步骤3：配置缓动

1. 根据动画类型选择缓动函数（参考 5.1-5.8）
2. 为不同属性设置不同缓动（位移用 position 缓动，缩放用 scale 缓动）
3. 如果使用 spring 或 gravity，配置对应物理参数

### 步骤4：配置拖影

1. 高速运动（位移 > 50px/帧）：启用拖影，trailCount: 3-5
2. 中速运动（位移 30-50px/帧）：启用拖影，trailCount: 2-3
3. 低速运动（位移 < 30px/帧）：禁用拖影

### 步骤5：配置交错

1. 多元素同时运动：启用 stagger，delayPerElement: 0.03-0.08
2. 单元素或需要同步运动：禁用 stagger

### 步骤6：生成 JSON

按照第三节的格式生成完整 JSON，确保：
- 所有元素的 `id` 在帧间正确匹配
- `x, y, width, height` 坐标正确
- `opacity` 在淡入淡出时正确设置（0→100 或 100→0）
- `animationConfig` 配置完整

## 九、错误避免

### ❌ 常见错误

1. **所有属性使用同一缓动** → 位移和缩放应有不同缓动曲线
2. **使用 linear 作为默认缓动** → 除非旋转/匀速平移，否则禁止使用
3. **高速运动不启用拖影** → 位移 > 50px/帧时必须启用拖影
4. **多元素同时运动不设置 stagger** → 多元素应交错出场
5. **帧间元素 id 不匹配** → 需要动画过渡的元素必须保持相同 id
6. **重物使用弹性缓动** → 重物应使用 easeOutExpo 或 gravity，不应有回弹
7. **轻物使用弹跳缓动** → 轻物应使用 easeOutElastic，弹跳是重物效果
8. **淡入淡出使用 easeInOutCubic** → 透明度应使用 easeInOutSine（更柔和）

### ✅ 正确做法

1. 位移默认 `easeInOutCubic`，缩放默认 `easeOutBack`，透明度默认 `easeInOutSine`
2. 根据物体重量选择缓动：重→指数/重力，轻→弹性/正弦
3. 高速运动启用拖影，低速运动关闭拖影
4. 多元素动画启用交错出场
5. 帧间保持元素 id 一致以实现平滑过渡
6. 先确定动画类型，再选择缓动配置
